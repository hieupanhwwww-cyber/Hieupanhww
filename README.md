# Tạo Ván (SketchUp)

Extension SketchUp (Ruby) tạo ván từ mặt, viết theo giao diện "Tạo Ván" của plugin zsu_vn.

## Cài đặt
SketchUp → Extensions → Extension Manager → Install Extension → chọn `dist/hieupanhww_taovan.rbz`.

## Dùng
- Extensions → Tạo Ván → **Tạo Ván**: rê chuột lên mặt (xem trước màu cam), bấm để tạo ván. `Tab` đảo hướng, `Esc` thoát.
- **Cài đặt Tạo Ván**: độ dày tự động (lấy theo ván gốc), độ dày thủ công (mm), đảo hướng, tạo component, tên/layer tự động hoặc tự đặt, tạo ván nhanh (từ mặt đang chọn, có gộp đồng phẳng).

## Chưa có so với bản mẫu
"Tính theo không gian" (chia không gian giữa các ván), "Mở rộng biên", "Bỏ qua xem trước", cài đặt mẫu (preset).

Chưa kiểm thử trong SketchUp thật (môi trường này không có SketchUp), mới kiểm tra cú pháp Ruby.
